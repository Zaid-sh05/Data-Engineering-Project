# Data Engineering Assignment - KNIME

This repository contains a KNIME workflow for a Data Engineering assignment.

## Files

- Data_Engineering_Assignment.knwf: KNIME workflow file.
- Sales Sample data.xlsx: Original input dataset.
- Data_Engineering_Valid.csv: Valid cleaned records.
- DE_Nonvalid_Records.csv: Invalid/non-valid records.

## How to open

1. Download the repository files.
2. Open KNIME Analytics Platform.
3. Go to File > Import KNIME Workflow.
4. Select Data_Engineering_Assignment.knwf.
5. Make sure the input file Sales Sample data.xlsx is available.
6. Run the workflow.

## Output

The workflow produces:
- Valid records file
- Non-valid records file
